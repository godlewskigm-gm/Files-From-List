## Polski

### Czym jest program

**Files From List** to program desktopowy do szybkiego zaznaczania plików w folderze źródłowym według listy nazw z pliku TXT, a następnie kopiowania lub przenoszenia ich do folderu docelowego.

Program jest całkowicie darmowy i **nie wymaga żadnej licencji** ani aktywacji.

### Cel

Program pomaga osobom, które dostają listę nazw plików (np. z Excela / eksportu) i muszą wyciągnąć dokładnie te pliki z większego katalogu.

### Jak uruchomić

1. Pobierz instalator z [Releases](https://github.com/godlewskigm-gm/Files-From-List/releases/latest) i zainstaluj **albo** uruchom **FilesFromList.exe**.
2. Windows 10/11.

### Format pliku TXT

- Jedna nazwa pliku w linii.
- Puste linie i linie zaczynające się od `#` są ignorowane.
- Dozwolone pełne ścieżki — brana jest sama nazwa pliku.
- Cudzysłowy wokół nazwy są usuwane.
- Duplikaty są usuwane.
- Kodowanie: UTF-8 (także z BOM), potem CP1250.

### Jak zacząć — krótki przepis

1. Wybierz **folder źródłowy** (lewy panel) i **folder docelowy** (prawy panel).
2. Wczytaj plik **.txt** z listą nazw.
3. Opcjonalnie włącz **Ignoruj wielkość liter** / **Ignoruj rozszerzenie**.
4. Kliknij **Zaznacz pliki z listy**.
5. Użyj **Kopiuj** albo **Wycinaj (przenieś)**.
6. Przy kolizjach nazw: nadpisz wszystkie / pomiń istniejące / anuluj.
7. Język: **PL** / **EN**. **O programie** — autor oraz zakładka Donate.

### Czego program nie robi

Nie przegląda podfolderów — listowane są tylko pliki bezpośrednio w wybranym folderze źródłowym.

Maksym Goldevskyi. Szczegóły praw autorskich: [About.txt](./About.txt).

## English

### What the program is

**Files From List** is a desktop app for quickly selecting files in a source folder according to a list of names from a TXT file, then copying or moving them to a destination folder.

The software is completely free and **does not require any license** or activation.

### Purpose

It helps people who receive a list of file names (e.g. from Excel / an export) and need to pull exactly those files out of a larger folder.

### How to run it

1. Download the installer from [Releases](https://github.com/godlewskigm-gm/Files-From-List/releases/latest) **or** run **FilesFromList.exe**.
2. Windows 10/11.

### TXT file format

- One file name per line.
- Empty lines and lines starting with `#` are ignored.
- Full paths are allowed — only the file name is used.
- Surrounding quotes are removed.
- Duplicates are removed.
- Encoding: UTF-8 (including BOM), then CP1250.

### How to start — short recipe

1. Choose the **source folder** (left panel) and **destination folder** (right panel).
2. Load a **.txt** file with the name list.
3. Optionally enable **Ignore case** / **Ignore extension**.
4. Click **Select files from list**.
5. Use **Copy** or **Cut (move)**.
6. On name conflicts: overwrite all / skip existing / cancel.
7. Language: **PL** / **EN**. **About** — author and Donate tab.

### What the program does not do

It does not scan subfolders — only files directly in the selected source folder are listed.
